# ============================================================
# 情侣网站 · robots.txt
# ------------------------------------------------------------
# 这是一个只给两个人看的小站，不希望被搜索引擎收录，也不希望被
# AI 训练爬虫抓取。
#
# ⚠️ 为什么这里不写 `Disallow: /`：
#    Google 官方明确「noindex 要生效，页面就不能被 robots.txt 拦住」——
#    全站 Disallow 会让爬虫根本读不到页面里的 noindex，反而可能留下
#    「无摘要」的链接。
#    这里只挡后台/接口/数据目录的理由**不是**「被挡住的 URL 不会出现裸链接」——
#    那条推论对任何 URL 都成立（被 Disallow 挡住的 URL 一样读不到 noindex 和
#    X-Robots-Tag）。真正的理由是：这些路径**本来就不该被抓取**，而且它们的访问
#    控制根本不在这层（见下面那段）。收录策略由响应头
#    `X-Robots-Tag: noindex, nofollow, noarchive` 与页面 <meta name="robots"> 负责。
#
# 真正的访问控制不是 robots.txt，而是服务端门禁
# （api/unlock.php 校验密码 → HttpOnly Cookie → 接口/照片按 Cookie 判定；
#   旧名 gate.php 会被部分主机的防护系统掐断连接，故改名，见 README）。
# ============================================================
