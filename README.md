# 💗 情侣网站 · 我们的家

一份用心准备的小惊喜 —— 纯 HTML / CSS / JavaScript 编写的情侣网站，
**零依赖、可离线运行**，双击 `index.html` 即可使用，也可以部署到任意静态托管平台（GitHub Pages / Netlify / 服务器）分享给 TA。

参考 GitHub 上开源情侣/纪念日项目（[romantic-gift-web](https://github.com/YU123-ZZZ/romantic-gift-web)、[Anniv-Project](https://github.com/GalihBimaa/Anniv-Project)）的长处，融合了：解锁仪式、实时恋爱计时、照片墙、时光轴、纪念日倒计时、情书、许愿瓶、默契问答游戏、内置音乐盒。

## 🌐 部署到服务器（在线访问）

### 第一步：构建

项目根目录运行（需要 Python 3）：

```bash
python tools/build.py
```

会在项目里生成 `dist/` 目录，**部署时上传 dist/ 里的内容**。构建脚本会自动给所有
CSS/JS/图片引用加上内容版本号（`style.css?v=3f9a2b1c`）：

- 改了代码 → 版本号自动变 → 浏览器必定拉新文件（部署后更新即时生效）
- 没改的文件 → 版本号不变 → 浏览器复用缓存（省流量、加载快）

> 不运行构建脚本直接传整个文件夹也能用，只是改代码后访客浏览器可能因缓存看不到更新
> （解决方法是手动强刷或等缓存过期）。

### 第二步：选择部署方式

**方式一：GitHub Pages / Netlify / Vercel（免费，推荐新手）**
把 `dist/` 内容推到仓库或用拖拽上传，平台自动配好 HTTPS。

**方式二：自有服务器（Nginx）**
1. 把 `dist/` 内容上传到服务器，如 `/var/www/love/dist`
2. 参考 `deploy/nginx.conf`，填进你的 Nginx 配置（或宝塔面板 → 网站 → 配置文件），
   记得改 `server_name` 和 `root`
3. 配置里已含：gzip 压缩（体积省 60%+）、静态资源 30 天长缓存、
   HTML 不缓存（更新即时生效）、安全头

**方式三：虚拟主机 / Apache**
把 `dist/` 内容上传到网站根目录，再把 `deploy/.htaccess` 也传上去（已配好压缩和缓存）。

### 第三步（可选）：分享卡片

7 个页面已带 `og:title` / `og:description` 标签，链接分享到微信/QQ 会显示标题和简介。
想要带图片的分享卡片，在页面 `<head>` 里加一行（换成你的完整域名）：

```html
<meta property="og:image" content="https://你的域名/assets/img/photo-1.svg">
```

### 常见问题

- **部署后改了 config 还是旧内容？** 重新运行 `python tools/build.py` 再上传，
  或让 TA 强刷一次页面（版本号已变的话刷新即新）。
- **图片/音乐不显示？** 确认文件名大小写与 `config.js` 里一致，路径以 `assets/` 开头。
- **需要 HTTPS？** GitHub Pages / Netlify 自带；自有服务器用
  `certbot --nginx` 一键申请免费证书，然后在 `deploy/nginx.conf` 里打开注释的 ssl 段落。

## ✏️ 如何改造成你们自己的

> ⭐ **第一步：把名字改成真的** —— 网站当前用占位名「待定A / 待定B」。
> 打开 `assets/js/config.js` 搜索「待定」，共 6 处需要替换成真名/昵称：
> 1. `names.boy` / `names.girl`（最关键，导航、主页标题、问候语、标签页标题全靠它）
> 2. 纪念日里的「待定A的生日 / 待定B的生日」（顺手把日期改成真实的）
> 3. 三封示例情书的署名（`sign` 字段）
> 4. 默契问答第 3 题选项（改成谁先表白的事实）
>
> 全部改完刷新页面即可，无需动其他文件。

**所有内容都集中在 `assets/js/config.js` 一个文件里**，改完刷新即生效：

```js
names:       你们的名字（导航、主页标题都会跟着变）
startDate:   在一起的日期（计时、纪念日都基于它）
password:    解锁密码（留空 "" 则取消密码，直接进入）
slogan:      主页大标语
greeting:    主页问候语（留空 "" 自动按时段问候）
messages:    情话轮播（想加几句就多加几句）
homeCards:   主页六个介绍卡片
anniversaries: 纪念日列表（"05-20" 表示每年都过，"2023-08-28" 表示一次性；
               农历生日加 lunar: true，date 写农历月-日如 "8-15"，
               闰月生日写 "闰4-15"（自动找下一个有该闰月的年份））
timeline:    时光轴事件（date / icon / title / text；date 写未来日期会显示"即将到来"样式）
gallery:     相册照片（src / cat 分类 / cap 说明）
letters:     情书（date / title / body / sign）
wishes:      许愿瓶（title / text）
quiz:        默契问答（q 题目 / opts 选项 / a 正确答案下标 0 开始）
truthDares:  真心话卡片题库（抽一张轮流回答）
compatQuiz:  默契度测试题（q / opts，无标准答案，两人各答一遍对比默契）
```

### 放你们的照片

把照片复制进 `assets/img/`，然后改 `config.js` 里 `gallery` 的 `src` 即可：

```js
{ src: "assets/img/photo-1.jpg", cat: "旅行", cap: "第一次旅行的海边" },
```

照片建议宽度 800px 以上；占位图会自动被替换，无需动其他代码。

### 手写情书 & 留言板 & 相册添加照片（存在哪）

「写新情书」「悄悄话留言板」和「相册里添加的照片」都保存在**打开网站的这台设备的浏览器本地**（localStorage），
不经过任何服务器，只有在这台设备上打开网站才能看到。
部署上线后，TA 在自己手机浏览器里写的话只有 TA 的手机看得到 ——
这是纯静态网站的天然限制，想要"真正的共享留言板/云相册"需要一个小后端（如需我可以帮你加）。

### 换背景音乐（可选）

网站自带一个用 WebAudio 合成的轻音乐盒旋律，不需要任何音频文件。
如果想用你们自己的歌：把 `music.mp3` 放进 `assets/music/` 目录，刷新后会自动优先播放它。

## 🎨 换主题色

打开 `assets/css/style.css` 顶部 `:root`，改几个变量就能整体换色：

```css
--rose:      #f06292;   /* 主色 */
--rose-deep: #d81b60;   /* 深色 */
--rose-soft: #f8bbd0;   /* 浅色 */
--bg:        #fff6f9;   /* 背景 */
```
